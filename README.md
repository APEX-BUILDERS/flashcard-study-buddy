# Flashcard Study Body

A clean, single-page flashcard study app for turning notes into quick review cards.

## Features

- Paste notes as one `question-answer` flashcard per line
- Smooth 3D card flip animation
- Previous, Next, and Shuffle controls
- Progress counter and progress bar
- Got It and Review Again answer tracking
- Results screen with score and percentage
- Retry only missed cards
- Fully responsive dark theme
- Keyboard shortcuts: Space to flip, Left and Right arrows to move

## How to Use

Open `index.html` in your browser, paste your notes, and click **Start Studying**.

## Note

This project was built entirely using Wispr Flow.
